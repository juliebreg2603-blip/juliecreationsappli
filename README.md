# Juliecreations – Application Java de vente 

Application Java de vente développée pour ma micro-entreprise **juliecreations**, dans le cadre de mon titre professionnel Concepteur Développeur d'Applications (2025-2026).

Elle fait partie d'une solution web complète : l'application est reliée par une API au site Symfony [juliecreations](https://github.com/juliebreg2603-blip/juliecreations), qui fournit les données (articles, stocks, profils).

## Technologies
- Java
- API reliée au site Symfony (récupération et envoi des données)
- Site Symfony (dépôt séparé : [juliecreations](https://github.com/juliebreg2603-blip/juliecreations))

## Fonctionnalités
- Connexion avec un compte
- Consultation de ses informations personnelles (profil)
- Consultation des articles et de leurs stocks, récupérés depuis le site
- Gestion du panier : ajout, modification et retrait d'articles
- Passage de commande
- Historique des commandes

## Lancer le projet
1. Cloner le dépôt
2. Ouvrir le projet dans votre IDE Java
3. Lancer l'application : elle se connecte directement à l'API du site
